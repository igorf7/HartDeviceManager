General information.
Supported HART versions: 4.0 – 7.5. The Hart Device Manager program is designed to check, configure, and program field devices with the HART protocol. The main program window contains a left and right panel, a menu bar, and a status bar (Status Bar). The left panel is responsible for connecting the computer’s communication port to the HART converter and detecting devices on the HART line.. The right panel consists of two tabs — “Configuration” and “Monitor” — each of which implements the corresponding functionality. The menu panel contains some additional program functions. The status bar displays the current state of the program and other operational information.

1. Getting started with the program.
1.1 Before launching the program, you need to connect a HART converter (for example, ICP i-7567) with a field device connected to it to the computer port.
1.2 Launch the Hart Device Manager program.
1.3 In the top left panel, select the port to which the converter is connected from the drop-down list (you can check this in the Windows Device Manager) and click the “Open” button.

2. Device search.
2.1 Connected devices must have a UNIQUE short address. The short address (polling address) can be set for the device on the “Configuration” tab. It is not allowed to have two or more devices with the same short address on the line.
2.2 Click the “Search for devices” button. The label on the button will change to “Stop Search.” The search status is displayed as a progress indicator above the button (visible only in the search state). As devices are detected, brief information about them will be displayed as lines in the list. Each such line displays the short address, serial number, and device type.
2.3 Upon completion of the search procedure, the message “Search completed” will be displayed. Now you can select one of the devices in the list for further work with it.
2.4 To select one of the devices, click the left mouse button on the corresponding line. In this case, the program reads additional information from the device and displays it in the output windows on the open tab. Selecting a device during the search process stops further search, just like the “Stop Search” button.

3. Configuration. Here you can read the configuration data from the device’s memory and, if necessary, change some of it.
3.1 Go to the “Configuration” tab. This tab is divided into three groups: “Device Identifier”, “Device Information”, “Device Parameters”.
3.2 If the list of devices is empty, perform a device search (step 2).
3.3 Select one of the devices in the list by clicking on the corresponding line. Wait for the current transaction to complete (the message “Exchange in progress” will disappear from the status line). If desired, you can re-read the data in the selected group by clicking the <Read> button.
3.4 If it is necessary to make changes* to the configuration of the selected device, you need to edit the data in the corresponding input/output fields and click the <Write> button.
* editing is not possible for some fields.

4. The monitor. On this tab, you can enable cyclic polling of the selected device.
4.1 Go to the "Monitor" tab.
4.2 If the list of devices is empty, perform a device search (step 2).
4.3 Select one of the devices in the list, if not selected. The "Identifier" group will display the serial number, unique address, and type of the selected device.
4.4 Press the <Start> button.
4.5 The measurement data is displayed in the corresponding output windows. The data is updated according to the specified survey period in the "Survey Period" input window.
4.6 Six parameters are output: 1st variable (PV), 2nd variable (SV), 3rd variable (TV), 4th variable (QV), current and percentage of range.
4.7 The graph of changes in the main parameter (1st variable) over time is displayed in the right area.
4.8 You can significantly reduce the polling time by checking the “Only the 1st variable” box; in this case, only the main parameter will be polled and displayed.
4.9 Below the <Start> and <Stop> buttons, the packet counter in the queue is displayed. If this counter is increasing, it means the selected polling period is too short and should be increased. If the counter is zero, the polling period can be reduced. This way, you can select the optimal polling period based on the readings of this counter.5. Menu Panel.
5.1 File-->Create...
5.2 File-->Open...
5.3 File-->Exit. Exit the program.
5.4 Settings-->Primary Master. The program works with field devices as a primary master (Primary Master).
5.5 Settings-->Secondary Master. The program works with field devices as a secondary master (Secondary Master).
5.6 Commands-->Restart. Reset the device. Similar to turning the power off and on.
5.7 Commands-->Self-diagnosis. Starts the self-diagnosis procedure in the device.
5.8 Commands-->Hardware reset. Returns to default settings. Resets all changes made to the device configuration.
5.9 Help-->Instructions. Displays a brief guide to working with the program.
5.10 Help-->About the program. Displays information about the program.6. Status bar.
6.1 The status bar is located at the very bottom of the program window. It displays various operational information about the program’s status or the execution of the current operation.

RU
Общие сведения.
Поддерживаемые версии HART: 4.0 - 7.5
Программа Hart Device Manager предназначена для проверки, настройки и программирования полевых устройств с HART-протоколом. Главное окно программы содержит левую и правую панель, панель меню и строку состояния (Status Bar). Левая панель отвечает за соединение комуникационного порта компьютета с HART-конвертером и обнаружение устройств на линии HART.
Правая панель состоит из двух вкладок - "Конфигурация" и "Монитор", каждая из которых реализует соответствующий функционал. Панель меню содержит некоторые дополнительные функции программы. Строка состояния отображает текущее состояние программы и другую оперативную информацию.

1. Начало работы с программой.
1.1 Перед запуском программы необходимо подключить к порту компьютера HART-конвертер (например ICP i-7567) с подключенным к нему полевым устройством.
1.2 Запустить программу Hart Device Manager.
1.3 На левой панели вверху выбрать в выпадающем списке порт, к которому подключен конвертер (можно уточнить в диспетчере устройств Windows) и нажать кнопку "Открыть".

2. Поиск устройств.
2.1 Подключенные устройства должны иметь УНИКАЛЬНЫЙ короткий адрес. Короткий адрес (адрес опроса, polling address) можно задать устройству на вкладке "Конфигурация". Наличие двух или более устройств с одинаковым коротким адресом на линии не допускается.
2.2 Нажать кнопку "Поиск устройств". Надпись на кнопке изменится на "Остановить поиск". Состояние поиска отображает индикатор прогресса над кнопкой (виден только в состоянии поиска). По мере обнаружения устройств, будет выводиться краткая информация о них в виде строк в списке. Каждая такая строка отображает короткий адрес, серийный номер и тип устройства.
2.3 По завершении процедуры поиска будет выведено сообщение «Поиск завершен». Теперь можно выбрать одно из устройств в списке для дальнейшей работы с ним.
2.4 Для выбора одного из устройств нужно кликнуть левой кнопкой мыши по соответствующей строке. При этом программа считывает из устройства дополнительную информацию и отображает ее в окнах вывода на открытой вкладке. Выбор устройства в процессе поиска останавливает дальнейший поиск так же как кнопка "Остановить поиск".

3. Конфигурация. Здесь можно прочитать конфигурационные данные из памяти устройства и, при необходимости, изменить некоторые из них.
3.1 Перейти на вкладку "Конфигурация". Эта вкладка разбита на три группы: "Идентификатор устройства", "Информация об устройстве", "Параметры устройства".
3.2 Если список устройств пуст, выполнить поиск устройств (п 2).
3.3 Выбрать одно из устройств в списке, кликнув по соответствующей строке. Дождаться завершения текущей транзакции (в строке состояния погаснет надпись "Идёт обмен"). При желании можно повторно прочитать данные в выбранной группе, нажав кнопку <Чтение>.
3.4 При необходимости внести изменения* в конфигурацию выбранного устройства, нужно отредактировать данные в соответствующих полях ввода-вывода и нажать кнопку <Запись>.
* для некоторых полей возможность редактирования отсутствует.

4. Монитор. На этой вкладке можно включить циклический опрос выбранного устройства.
4.1 Перейти на вкладку "Монитор".
4.2 Если список устройств пуст, выполнить поиск устройств (п 2).
4.3 Выбрать одно из устройств в списке, если не выбрано. В группе "Идентификатор" отобразится серийный номер, адрес (unique address) и тип выбранного устройства.
4.4 Нажать кнопку <Старт>.
4.5 Данные измерений выводятся в соответствующих окнах вывода. Обновление данных происходит в соответствии с заданным периодом опроса в окне ввода "Период опроса".
4.6 Выводятся шесть параметров: 1-я переменная (PV), 2-я переменная (SV), 3-я переменная (TV), 4-я переменная (QV), ток и процент диапазона.
4.7 В правой области отображается график изменения основного параметра (1-я переменная) во времени.
4.8 Можно значительно сократить время опроса, установив флажок "Только 1-я переменная", при этом опрашиваться и выводиться будет только основной параметр.
4.9 Под кнопками <Cтарт> и <Стоп> отображается счетчик пакетов в очереди. Если этот счетчик растет, значит выбранный период опроса слишком мал и его следует увеличить. Если счетчик равен нулю, период опроса можно уменьшить. Таким образом можно подобрать оптимальный период опроса, ориентируясь на показания этого счетчика.

5. Панель Меню.
5.1 Файл-->Создать...
5.2 Файл-->Открыть...
5.3 Файл-->Выход. Выход из программы.
5.4 Параметры-->Первичный мастер. Программа работает с полевыми устройствами как первичный мастер (Primary Master).
5.5 Параметры-->Вторичный мастер. Программа работает с полевыми устройствами как вторичный мастер (Secondary Master).
5.6 Команды-->Рестарт. Сброс устройства. Аналогично выключению и включению питания.
5.7 Команды-->Самодиагностика. Запускает процедуру самодиагностики в устройстве.
5.8 Команды-->Аппаратный сброс. Возврат к настройкам по умолчанию. Сбрасывает все изменения, внесенные в конфигурацию устройства.
5.9 Справка-->Инструкция. Отображает краткое руководство по работе с программой.
5.10 Справка-->О программе. Отображает сведения о программе.

6. Строка Состояния.
6.1 Строка состояния находится в самом низу окна программы. Здесь отображается различная оперативная информация о состоянии программы или выполнении текущей операции.
